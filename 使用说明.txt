双摆混沌地图 v1.0
================

启动：双击 ChaosMap.exe（会铺满屏幕）

主窗口操作
----------
  左键拖框      放大到选区并重新计算
  Z             返回上一个视图
  Home          回到全域
  Ctrl + 滚轮   纯视觉缩放（不重算，只是为了看清细节）
  右键拖动      缩放后平移画面
  Ctrl + 0      缩放复位
  + / -         放大 / 缩小
  Ctrl + S      把当前图像存成 PNG 到桌面
  双击图像       打开该点对应的双摆动画
  F1            显示这份说明

顶部控件
--------
  精度        渲染分辨率（64 ~ 16384），默认 4096
  时长        每个双摆模拟的物理时长（秒）
  重新模拟    按当前参数重算
  单精度      最快，抖动较大
  高精度      float-float 双精度模拟（约 15 位有效数字），推荐
  双精度      真 fp64，最慢，用于需要极限精度的场合
  快速模式    -cl-fast-relaxed-math，再快 4 倍，精度约 2^-21
  保存图片    存 PNG 到桌面
  高级选项    改质量、摆长、重力、初始角速度 / 初始角度，切换参数空间

高级选项
--------
  第一/第二摆质量 m1 m2
  第一/第二摆长度 L1 L2
  重力加速度 g
  两个初始角速度 w1 w2（可填 -pi/2、-π/3、2*pi 这类表达式）
  参数空间：角度空间（横纵轴是两摆初始角度）/ 角动量空间（横纵轴是初始角速度）

双摆窗口操作
------------
  空格        暂停 / 继续
  上下箭头    调速
  R           重置
  P           播放 / 停止声音
  M           切换声频模式（实时流式 / 周期循环）
  [ ]         调整加速倍率 / 音高
  T           导出当前轨迹图（含初始设定、起终点、速度箭头）到桌面

颜色含义
--------
  黑 = 有序（准周期，Lyapunov 指数低）
  蓝 = 过渡
  白 = 混沌（Lyapunov 指数高）

源码
----
  src\chaosmap.c   主程序（Win32 GUI + 双摆窗口 + 声音）
  src\cl_gpu.c     OpenCL 后端（单精度 / float-float / fp64 三套内核）
  src\cl_gpu.h
  srcuild.bat    重新编译

重新编译需要 MinGW-w64 gcc 和显卡的 OpenCL.dll（显卡驱动自带）。
