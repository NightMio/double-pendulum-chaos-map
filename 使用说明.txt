双摆混沌地图 · 使用说明
ChaosMap - User Guide
================================================================

【运行 / Running】

  中文界面 / Chinese UI :  ChaosMap.exe
  英文界面 / English UI :  ChaosMap-en.exe

  双击即可，程序会自动铺满屏幕并开始计算。
  需要 Windows 10/11 和支持 OpenCL 的显卡（NVIDIA / AMD / Intel 核显均可）。
  Double-click to run. It auto-maximizes and starts computing.
  Requires Windows 10/11 and an OpenCL-capable GPU.


【这张图是什么意思 / What the map means】

  每个像素 = 一个初速度为零的双摆，坐标为两个摆的初始角度（-π ~ π）。
  颜色越白 = 该处越混沌，越黑 = 越稳定（准周期），蓝色是过渡。
  Each pixel is a double pendulum with zero initial velocity; axes are the
  two initial angles (-pi..pi). White = chaotic, black = ordered, blue = transition.


【主窗口操作 / Main window】

  左键拖框        放大到框选区域并重新计算
                  Drag: zoom into the selection and recompute
  Z               返回上一视图
                  Go back to the previous view
  左键双击        打开该点的双摆动画
                  Double-click: open the pendulum at that point
  Ctrl+滚轮       纯视觉缩放（不重新计算），1x~64x
                  Ctrl+Wheel: visual zoom only (no recompute)
  右键拖动        平移画面
                  Right-drag: pan
  精度            每边采样点数，64~16384（默认 4096）
                  Precision: samples per side, 64-16384 (default 4096)
  时长            每个双摆演化多久（秒），越大 λ 越准
                  Duration: evolution time per pendulum in seconds
  单/高/双精度    单精度最快；高精度(float-float)平衡；双精度最准但慢
                  Single / High (float-float) / Double
  快速模式        fast-math 内核，约快 3.7 倍，细节略有差异
                  Fast mode: fast-math kernel, ~3.7x faster
  锐度            λ 到颜色的映射指数，越大黑白分界越硬
                  Sharpness: exponent of the lambda->color mapping
  保存图片        按 1:1 存 PNG 到桌面
                  Save PNG: 1:1 render to Desktop
  高级选项        质量、摆长、重力、初始角速度/角度、参数空间
                  Advanced: mass, length, gravity, initial state, space
  放大/缩小/复位  视觉缩放的按钮版
                  Zoom +/-/Reset buttons
  使用说明        打开本文件
                  Help: open this file

【两种参数空间 / Two parameter spaces】

  角度空间      横纵轴 = 两个摆的初始角度（-π ~ π），初速度为零
                Angle space: axes = initial angles, zero initial velocity
  角动量空间    两个摆竖直向下，横纵轴 = 初始角速度（-25 ~ 25）
                Angular-velocity space: hanging down, axes = initial ang. vel.
                负值表示顺时针 / Negative = clockwise

  角动量空间必须用高精度或双精度：单精度在这里会严重高估 λ。
  In angular-velocity space always use High or Double; fp32 overestimates lambda.


【声音是怎么来的 / How the audio works】

  把连续角度 θ(t) 以 440 倍的速率压缩成音频。演示摆保持实时，
  另有一个独立的"声音摆"以 440 倍速跑同一初值，写进环形缓冲，
  音频按 1:1 读出来，所以永远不会循环。
  theta(t) is time-compressed 440x into audio. The demo pendulum stays
  real-time; a separate "audio pendulum" runs the same initial condition
  440x faster into a ring buffer, played back 1:1 so it never loops.

  实时流式：一直放，永不重复 / live stream: continuous, never repeats
  周期循环：先检测周期再循环播放 / periodic loop: detect period, then loop


【导出音频 / Export audio】

  有 ffmpeg 时存成 OGG（体积小），没有则自动存成 WAV（未压缩，约 1.7MB/10s）。
  安装 ffmpeg：  winget install Gyan.FFmpeg
  With ffmpeg it saves OGG; without it falls back to uncompressed WAV.
  Install ffmpeg:  winget install Gyan.FFmpeg


【常见问题 / FAQ】

  Q: 图里出现方格或纯色块？
     A: 放大太深，超出单精度分辨率。换高精度或双精度。
     A: Zoomed past fp32 resolution. Switch to High or Double.

  Q: 角动量空间几乎全白？
     A: 用单精度算的，λ 虚高数百倍。换高精度。
     A: Computed in fp32, lambda inflated hundreds of times. Use High.

  Q: 双精度很慢？
     A: 这块卡的 fp64 只有 fp32 的 1/64 吞吐，慢是正常的。
     A: fp64 runs at 1/64 of fp32 throughput on consumer GPUs.

  Q: 出问题想看日志？
     A: 程序目录下的 chaosmap_log.txt
     A: See chaosmap_log.txt next to the exe.
